# Work Performance

Ứng dụng quản lý công việc và phân tích hiệu suất, ưu tiên sử dụng cá nhân trước và sẵn sàng mở rộng đội nhóm.

## Trạng thái

Đang lập kế hoạch — yêu cầu sản phẩm và kiến trúc chưa được phê duyệt.

## Quy trình Git

- `main`: branch ổn định.
- `dev`: branch tích hợp phát triển.
- `feature/*`: branch riêng cho từng task.

WP-001 (PRD v1.0) đang ở trạng thái bản nháp chờ nghiệm thu. Chưa khởi tạo source code ứng dụng.
